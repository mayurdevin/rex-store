How it works

  1. Publish: FormData → /.netlify/functions/publish → create Release slug-v1.0.0 → upload APK → upload images → update data/apps.json.
  2. Edit: Same form prefilled → if version/APK changed → new Release; else → /.netlify/functions/update only updates metadata, keeps apkUrl.
  3. Delete: /.netlify/functions/delete → remove GitHub Release + tag → remove from apps.json → disappears from store.
  4. Token stays server-side; GitHub is source of truth for APKs.

Delete app?

This will remove the app from data/apps.json and delete its GitHub Release and tag. Old APK will no longer be downloadable. This cannot be undone.
