How it works (technical)

  1. Frontend converts APK/icon/screenshots to base64 and POSTs JSON to /.netlify/functions/publish.
  2. Function (server-only) uses GITHUB_TOKEN from env to call GitHub API: POST /repos/:owner/:repo/releases to create a release with tag app-id-vX.Y.Z.
  3. Uploads APK binary to https://uploads.github.com/.../assets?name=app.apk — response gives browser_download_url.
  4. Uploads icon/screenshots via Contents API to images/apps/<id>/ and builds raw URLs.
  5. Fetches, merges, and commits updated data/apps.json via Contents API. Next page load shows the app.
  6. Token never exposed to browser; all GitHub calls are in the Function.
